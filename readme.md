# Eventure — Prototype V1 showcase

Version visuelle et PWA-ready du prototype Eventure.

Pour l'ajouter à un écran d'accueil de façon fiable, héberger ce dossier sur un domaine HTTPS (Netlify, Vercel, GitHub Pages, etc.), puis ouvrir l'URL dans Chrome/Safari et choisir « Ajouter à l'écran d'accueil ».

Le fichier index.html peut être ouvert localement pour démo, mais l'installation PWA/service worker nécessite généralement un hébergement HTTPS.
